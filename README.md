# Тёмный архив — сайт для статей

Это первый рабочий вариант сайта-блога под Vercel.

## Что уже есть

- главная страница со статьями;
- отдельная страница статьи;
- тёмная и светлая тема;
- адаптация под телефон;
- вход администратора;
- добавление, редактирование и удаление статей;
- черновики и публикация;
- формальная регистрация читателей;
- лайки;
- комментарии;
- личные подборки;
- robots.txt и sitemap.xml.

## Демо-вход администратора

Логин: `admin`

Пароль: `1234`

## Как запустить на компьютере

1. Установи Node.js с сайта nodejs.org
2. Распакуй архив
3. Открой папку проекта в терминале
4. Выполни команды:

```bash
npm install
npm run dev
```

После этого сайт откроется по адресу, который покажет терминал.

## Как бесплатно выложить на Vercel

1. Создай аккаунт на GitHub.
2. Создай новый репозиторий.
3. Загрузи туда файлы из этой папки.
4. Создай аккаунт на Vercel.
5. Нажми Add New Project / Import Project.
6. Выбери репозиторий.
7. Vercel сам поймёт, что это Vite-проект.
8. Нажми Deploy.

## Важно

Сейчас сайт хранит статьи, пользователей, лайки и комментарии в браузере через localStorage.

Это удобно для теста, но для настоящего сайта нужно следующим этапом подключить Supabase:
- база данных для статей;
- нормальная регистрация;
- хранение комментариев;
- хранение лайков;
- загрузка изображений.
